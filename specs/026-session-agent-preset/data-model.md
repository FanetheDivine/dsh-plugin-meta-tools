# Data Model: 配置新增会话的预设

## DefaultPresetConfig

| 配置键 | 类型 | 默认值 | 规则 |
| --- | --- | --- | --- |
| session_preset | string | `''` | 去除首尾空白；空值表示跟随宿主默认；不参与成对校验 |

配置页把该字段并入现有草稿；保存时一次写入，放弃时恢复，只读与热更新行为与模型字段一致。

## PresetRosterRow

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | 预设标识，同时作为名称缺失时的显示值 |
| name | string? | 预设显示名 |
| description | string? | 预设用途说明 |
| isDefault | boolean? | 是否为宿主“新任务默认预设” |
| broken | string? | 不可用原因；存在时不可选择 |

客户端与后端使用同一形状。客户端从 `ctx.remote.agentPresets.list()` 读取；后端从 `agentPresets.list()` 读取。

## PresetOption

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| id | string | `''` 表示“跟随宿主默认”，其余为预设标识 |
| label | string | 预设名称；名称为空时使用标识 |
| unavailable | boolean | 已保存值不在可用名册或标记为损坏 |

菜单顺序：先“跟随宿主默认”，再按宿主名册顺序列出可用预设。已保存但不可用的值额外以禁用项显示。

## PresetResolution

新会话预设按以下顺序解析：

1. **显式参数**：`agent_preset` 去除空白后非空，直接使用，由宿主校验。
2. **配置可用**：配置值在宿主可用名册中，使用配置值。
3. **回退宿主默认**：配置为空、配置值不可用或名册读取失败，按空值创建。
4. **未配置**：无显式参数且配置为空，按空值创建，与现有行为一致。

解析结果只作用于本次新建会话，不写回配置与宿主设置。

## PresetSelectorState

| 状态 | 触发显示 | 菜单 | 说明 |
| --- | --- | --- | --- |
| loading | 加载中，禁用 | 不打开 | 首次读取名册 |
| ready | 当前预设名或“跟随宿主默认” | 可打开 | 名册可用 |
| unavailable | 已保存值，标注不可用 | 可打开，仅列可用预设与跟随项 | 配置值不在名册 |
| noService | 禁用并说明 | 不打开 | 宿主未提供预设能力 |
| error | 禁用并显示失败 | 不打开 | 名册读取失败，提供重试 |

选择动作只调用表单 `edit('session_preset', id)`，不直接保存，也不调用宿主设置写入。
