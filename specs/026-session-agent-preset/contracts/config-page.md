# Contract: 配置页“新增会话”区域

## 布局

“新增会话”区域自上而下两行：

1. “模型”行：沿用官方模型与推理等级选择器。
2. “预设”行：标签、右侧 select 触发器与说明。

| 元素 | 中文 | 英文 |
| --- | --- | --- |
| 模型标签 | 模型 | Model |
| 预设标签 | 预设 | Preset |
| 预设说明 | 选择新建会话时使用的预设 | Choose the preset AI uses for new sessions. |
| 跟随宿主默认 | 跟随宿主默认 | Follow Host default |
| 加载中 | 加载中… | Loading… |
| 不可用 | 不可用 | Unavailable |
| 无预设能力 | 此部署不提供预设 | This deployment provides no presets. |
| 加载失败 | 预设加载失败 | Could not load presets |
| 重试 | 重试 | Retry |

## 触发器

- 未选择：显示“跟随宿主默认”。
- 已选择可用预设：显示预设名称；名称为空时显示标识。
- 已选择不可用预设：显示名称或标识，并追加“不可用”。
- 名册加载中、加载失败或宿主无预设能力：触发器禁用。

## 菜单

- 使用 DSH 自带 `Menu`，从触发器向下展开，空间不足时由 Menu 自行翻转。
- 首项“跟随宿主默认”，选择后写入空值。
- 其后按名册顺序列出可用预设，当前值显示选中标记。
- 不可用的已保存值以禁用项显示，并标注“不可用”。
- 支持方向键移动、回车选择、Esc 关闭并返回触发器焦点。
- 浮窗通过 portal 渲染，避免被配置页容器裁切。

## 行为

- 选择只修改配置草稿，不直接保存，也不修改宿主“新任务默认预设”。
- 保存后热更新，作用于后续未显式传参的新建会话。
- 放弃草稿恢复已保存值；只读与保存失败沿用现有配置页行为。
- 名册加载失败时保留已保存值，并提供重试。
- 关闭 `session_create` 时选择器仍可编辑，配置保留。
