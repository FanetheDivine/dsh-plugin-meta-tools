# Contract: session_create 预设

## 参数

| 参数 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| agent_preset | string | 否 | 预设标识；接受首尾空白，空白按未提供处理 |

## 解析顺序

1. 显式 `agent_preset` 非空：使用显式值，由宿主校验。
2. 配置 `session_preset` 非空且在宿主可用名册中：使用配置值。
3. 其余情况：不传预设，宿主使用“新任务默认预设”。

后端在每次创建时读取宿主可用名册；名册读取失败按空值处理。配置值不在可用名册或标记为损坏时按空值处理，不阻断创建。

## 返回

现有字段保持不变：`sessionId`、可选 `agentPreset`、可选 `title`、`prompted`。`agentPreset` 为宿主实际记录的预设。

## 错误

| 情况 | 结果 |
| --- | --- |
| 显式预设不存在或损坏 | 宿主拒绝，返回可理解的错误；不设置标题、不投递首条消息 |
| 配置预设不可用 | 按未配置处理，改用宿主默认，不返回预设错误 |
| 宿主未提供预设能力 | 按未配置处理，新建会话沿用宿主行为 |
| 预设与模型、标题或首条消息同时提供 | 各项独立生效；模型配置在会话创建后应用 |

## 兼容性

未保存 `session_preset` 时，现有请求的参数、返回结果与行为保持不变。显式 `agent_preset` 的既有错误行为保持不变。
