# Quickstart: 元工具品牌与面向用户的说明

## 自动检查

```sh
pnpm format && pnpm full-check
```

期望：全部通过；元数据测试断言新标题与描述，配置页测试断言三组、十一行说明与开关。

## 宿主核对

1. 运行 `pnpm build`，刷新已加载本插件的 DSH 页面。
2. 打开“插件”页，找到本插件：
   - 标题为“元工具”，描述以“为 AI 提供修改自身运行环境的元工具”开头。
   - 图标为扳手加环绕箭头，明暗主题下清晰，没有底板。
3. 打开本插件详情页：README 以元工具定义开头，没有安装命令、配置键表与工具参数表。
4. 打开插件行配置页：
   - 三个分组标题依次为工作区、查看会话、管理会话。
   - 每个开关有标签与说明。
   - 关闭一个开关并保存，该工具从模型可用工具中消失。
5. 把界面语言切到 English，重复第 2 至 4 步。
6. 把窗口宽度调到 390 px，说明换行，开关不被挤出。
