# 国际化

插件文案分两处：`locale/*.json` 供宿主在插件未激活时读取插件标题与描述，`src/client/locales.ts` 供浏览器渲染配置页文案。两处都由宿主的 locale 服务解析。

## 约束

- 所有用户可见的前端文案 MUST 来自 locale 字典；组件、样式与逻辑代码 MUST NOT 出现界面字符串字面量。
- `src/client/locales.ts` 的中文字典是键集事实源；英文字典 MUST 覆盖同一键集，缺键或空文案 MUST 使测试失败。
- 字典 MUST 在浏览器入口通过 `ctx.locale.register(<包名>, { zh, en })` 注册，组件只通过 `t(key)` 读取。
- 新增或修改界面文案 MUST 同时更新中英文字典与配置页测试。
- 图标、图片等静态资源 MUST NOT 承载需要翻译的文案；可访问名称使用包名或与界面语言无关的标识。
- 模型面向的工具契约文案不经过前端 locale，保持英文并遵循[工具契约](./how-it-works.md#工具契约)。
- `meta.title` 与 `meta.description` MUST 为每种基线语言各写一份，各文件的 `meta` 键集 MUST 一致。
- 元数据资源 MUST 在 `package.json` 的 `exports` 与 `files` 中声明。
- 译文 MUST 保留占位符、斜杠命令与 API 字段名的原文。
- locale 资源 MUST 不含零宽空格 U+200B 与 BOM U+FEFF。
- 文案与元数据的变更 MUST 由测试覆盖结构、键集与打包内容。

界面语言由宿主切换，硬编码文案会与语言设置不一致，并绕开字典完整性检查。宿主按语言回退链读取元数据与字典；缺一份基线语言或漏掉打包声明时，用户看到英文包名或键名。

## 元数据资源

| 文件 | 内容 |
| --- | --- |
| `locale/zh.json` | 中文标题与描述 |
| `locale/en.json` | 英文标题与描述 |

`meta` 字段：

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `meta.title` | 是 | 插件行与详情页的标题，单行 |
| `meta.description` | 是 | 一句话说明插件能力 |
| `meta.detail` | 否 | 详情页文档路径，指向包内 Markdown；省略时详情页使用 `README.md` |

宿主读取行为：

- 当前语言没有资源文件时，沿回退链取下一份，最终回落 `en`。
- 缺 `meta.title` 或 `meta.description` 时，回落 `package.json` 的 `name` 与 `description`。
- 插件停用状态下照常读取。

## 包清单声明

```json
{
  "exports": { "./locale/*.json": "./locale/*.json" },
  "files": ["dist", "cordis.patch.yml", "locale/*.json", "icon.svg", "README.md"]
}
```

漏掉 `exports` 时宿主读不到元数据；漏掉 `files` 时发布包缺文件。

## 前端字典

- 命名空间为 `dsh-plugin-meta-tools`，字典在 `src/client/locales.ts`，中文字典是键集事实源。
- 每个工具有 `config.<tool>.label` 与 `config.<tool>.description` 两个键：标签同时用作开关的无障碍名称，说明显示在标签下方。
- 每个能力分组有一个 `config.group.<分组键>` 键，分组键取自 `src/constants.ts` 的 `TOOL_GROUPS`。
- `apply` 里注册：`ctx.locale.register(NS, { zh, en })`。
- 槽位注册传 `locale: NS`，组件通过注入的 `t` 取文案。
- 新增工具时补 `config.<tool>.label`、`config.<tool>.description`、同名开关，并把工具加入一个分组。
- 槽位之外的文案用 `ctx.locale.bind(NS)`。
- 键名并入 `LocaleNamespaceMap`，缺失的键在编译期报错。

## 语言与回退

- 用户在 Settings → General → Language 选择语言，选择写入宿主设置并跨浏览器生效。
- 未选择时按浏览器语言匹配已注册语言，匹配失败回落 `en`。
- 查找顺序：当前语言 → 该命名空间 → `common` 命名空间 → 键名。
- 切换即时生效，`<html lang>` 同步更新；注册时捕获的文案保持注册时的语言。

## 新增一种语言

1. 复制 `locale/en.json` 为 `locale/<id>.json`，翻译 `meta.title` 与 `meta.description`。
2. 英文标题用 sentence case，只大写首词与专有名词。
3. 语言 id 不在宿主内置集合内时，先由语言包调用 `ctx.locale.addLanguage({ id, label, fallback: 'en' })`。
4. 在 `src/client/locales.ts` 增加同键集字典，并加入注册调用。
5. 更新 `tests/metadata.test.ts` 的基线列表与 `tests/client.test.ts` 的字典断言。
6. 运行 `pnpm format && pnpm full-check`。

## 校验

| 命令 | 检查 |
| --- | --- |
| `pnpm test:code` | 元数据测试：结构、键集、禁用字符与清单声明 |
| `pnpm full-check` | 类型、lint、源码测试、构建与产物测试 |
| `npm pack --dry-run --json` | 发布内容包含全部 `locale/*.json` |

实机核对：在“插件”页切换语言，核对本插件的标题与描述随之变化，停用状态下照常显示。
